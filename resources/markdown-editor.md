# 博客 Markdown 编辑

管理页提供富文本、Markdown 源码和当前草稿阅读预览，持久化正文仍只有 Markdown。
桌面采用可调双栏，窄屏按需切换单栏；正文与预览独立滚动。分隔条支持拖动、方向键（Shift 加快）、Home/End 和双击/Enter 复位。
打开文章、切换模式不会自动保存，也不会把未修改正文重新序列化。

| 内容                                               | 富文本能力           | 保真策略                                                                    |
| -------------------------------------------------- | -------------------- | --------------------------------------------------------------------------- |
| 标题、段落、强调、删除线、引用、链接、多层普通列表 | 可编辑               | 同一 TipTap Schema 校验 Markdown 输出的语义                                 |
| GFM 表格                                           | 编辑单元格、增删行列 | 仅支持单段单元格与列对齐；不提供合并单元格或删除表头                        |
| 任务列表、嵌套任务列表                             | 可勾选、编辑         | 保留完成状态与层级                                                          |
| 普通项与任务项混排                                 | 源码编辑             | 当前 TipTap 转换可能改变混排结构，检测失败时禁止富文本打开                  |
| 代码围栏、语言、文件名                             | 代码文本可编辑       | 未修改时保留原围栏；编辑后使用足够长的围栏，info string 保留                |
| Mermaid                                            | 编辑代码原文         | 保留 mermaid 语言标识，图表由当前草稿的 BlogRenderer 预览负责               |
| 数学公式                                           | 原文特殊节点         | 表达式不可在富文本内改写；切换源码修改，预览负责数学排版                    |
| 图片                                               | 显示授权图片投影     | src 保存稳定引用，不把签名 URL 写回正文；编辑图片视图与阅读预览共用资源解析 |
| 附件                                               | 编辑链接文本         | asset://id、resource://key 只作为稳定身份，不在编辑 DOM 中直接导航          |
| 行内 HTML、引用定义、脚注、特殊扩展                | 源码编辑             | 检测到不可靠转换时保留完整原文，并说明原因                                  |
| 可独立识别的 HTML 块                               | 原文保护节点         | 仅按文本显示，不执行 HTML 或作者属性；修改内容请使用源码模式                |
| 超过 60,000 字符的正文                             | 源码编辑             | 避免大型 ProseMirror 文档影响浏览器操作；阅读预览不受此阈值限制             |

## 资源与保存

- 使用原有“插入图片”“插入附件”上传入口，上传成功追加 asset://id。
- 保存仍由后端校验和转换为 resource://key，资源投影中的临时 URL 不进入编辑缓冲。
- 实时预览使用正式 BlogRenderer，接收校验成功的当前 Markdown 草稿；隐藏的窄屏预览暂停更新，打开后再同步。
- 富文本停止连续输入后校验往返，待校验期间禁止保存；阅读预览独立防抖并在 Worker 解析，长文复用现有渐进挂载。
- 富文本粘贴只读取剪贴板纯文本，能安全识别时按 Markdown 插入；不接受作者 HTML。
- 若输出无法可靠恢复编辑状态，保存、发布等操作被阻止。模式切换也会被阻止，当前富文本输入及撤销栈继续保留。可以撤销错误操作后重试，或明确放弃本次富文本修改并恢复最后一次校验通过的源码。不会将编辑器异常时发出的纯文本当作恢复源码。
- 基础 Markdown 的空白和标记样式可能在实际编辑后规范化；仅打开或切换模式不会产生这种变化。

保存、发布、下架、导出、版本冲突和权限仍由原 Blog API 与管理流程处理。
