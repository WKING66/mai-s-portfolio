# Mermaid 容器拖拽与尺寸调整

父分支 `feature/blog-reader-performance-mobile`，基点 `0d2e05c`；功能分支 `feature/mermaid-inline-pan-resize`。维护者两处 Portfolio 后端未提交修改完整保留，未暂存。未修改 Markdown、API、权限或博客生命周期。

## 交互与参考

参考[飞书官方文本绘图说明](https://www.feishu.cn/hc/zh-CN/articles/496118428959-%E4%BD%BF%E7%94%A8%E6%96%87%E6%9C%AC%E7%BB%98%E5%9B%BE%E5%B0%8F%E7%BB%84%E4%BB%B6)的全屏模式、拖动区域边界调整比例及源码/图表切换。只读取了公开说明，未访问登录后的编辑器或内部源码；本文的正文缩放、平移与容器尺寸调整是针对本站阅读需求的实现，并不声称复刻飞书内部实现。

- 正文与全屏均可鼠标拖拽平移；移动超过 5 CSS px 才进入拖拽，松手不会误打开全屏。普通点击仍可打开全屏。
- Ctrl＋滚轮按鼠标位置缩放；普通滚轮继续滚动文章。现有缩放按钮、适应容器、键盘缩放和平移保留。
- 正文右下角手柄可调整显示区域宽高。尺寸手柄使用原生 Pointer Capture 与现有 UButton，可鼠标/触摸操作，方向键微调，Home 或“恢复尺寸”恢复默认。
- 宽度限制在外层可用空间内，并保存为局部百分比。屏幕变窄时自然收缩，未增加按设备型号分支。高度有上下限，防止无限扩大。
- 自动适配状态下调整尺寸会重新适配；手动缩放/移动后调整尺寸保留比例。“适应容器”重新居中。尺寸/镜头状态只存在组件内，不写入正文或存储。
- 触屏默认保留纵向滑动阅读；开启“触屏拖拽”后可单指在图内自由平移，关闭即可恢复阅读。全屏始终可单指平移。触屏手柄为独立 44px 触摸目标。
- 源码仍位于图表上方；复制、主题与全屏焦点恢复、安全 SVG 边界保留。

Reka Splitter 已用于双面板编辑器，但本次没有第二块待分配面板，未引入空面板或新依赖。复用 `BlogMermaidCanvas` 的镜头与 ResizeObserver，仅扩展本地 Pointer 更新路径；拖拽更新 transform，尺寸调整更新容器样式。不扫描全文，不重复执行 Mermaid/Shiki。

## 验收地址与边界

前端继续 `http://127.0.0.1:3000/design-showcase#mermaid-reading`；后端保持 `127.0.0.1:9333`。LAN 沿用原监听，热点地址随 DHCP 变化，不硬编码。未开启额外验收服务。

展示高度调整会自然改变后续正文位置，这是主动调整区域尺寸的预期效果；没有逐帧高度过渡。尺寸不跨路由保存，暂未提供双指捏合。性能结论限于本次实际图表交互回归，不替代维护者长文章阅读与真机确认。
