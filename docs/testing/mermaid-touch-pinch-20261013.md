# Mermaid 触屏缩放与尺寸控件撤回

父分支 `feature/blog-reader-performance-mobile`，基点 `e615496`；功能分支 `feature/mermaid-touch-pinch`。保留维护者两处 Portfolio 后端修改，以及工作期间新增的 `docs/architecture/diagrams/document/01-overview.mmd` 修改；均未暂存或提交。

## 修改与取舍

根据真机反馈移除容器宽高调整、右下角手柄、恢复尺寸按钮、尺寸状态及对应键盘/指针处理。容器恢复自动适配，旧尺寸调整报告保留为历史记录，以本报告为当前行为。

触摸交互与桌面输入分开：桌面仍使用 Pointer 拖拽和 Ctrl＋滚轮；触屏使用 TouchEvent 多点触摸。双指距离比控制缩放，手势中心控制锚点和移动，沿用已有缩放上下限。双指缩放在正文和全屏均可直接使用，不必开启触屏拖拽。触屏工具栏改为“双指缩放”提示，隐藏桌面 Ctrl 提示。

正文单指默认滚动文章，启用“触屏拖拽”后可平移；全屏单指始终可平移。双指变单指时暂停该次手势的平移，全部抬手后可开始新手势。缩放、拖动与取消会抑制合成点击，防止误进入全屏。工具栏和正文画布是独立交互区域，触屏点击“适应容器”已验证不打开全屏。保留加减按钮以提供无需双指的替代操作。

事件只更新已有 camera/transform，不改 SVG、Markdown、API、主题状态或资源数据。未增加依赖，未修改 Mermaid 安全过滤或正文解析。TouchEvent 处理参考 [MDN 多点触控说明](https://developer.mozilla.org/en-US/docs/Web/API/Touch_events/Multi-touch_interaction)。

## 验收与边界

继续使用 `http://127.0.0.1:3000/design-showcase#mermaid-reading`；后端保持 9333。沿用原局域网监听，不新增验收端口。手机刷新原热点地址即可测试。
